# Contributing

Thank you for helping improve the Hack for Earth 2026 technical workspace.

This repository supports **HACK4EARTH 2.0 — Greener Fields**. The competition itself is hosted on Kaggle; this repository is for shared technical guidance, examples and programme resources.

## Useful contributions

We welcome:

- documentation fixes
- clearer setup instructions
- improvements to reference examples
- corrections to resource links
- accessibility improvements
- reproducibility improvements
- small technical utilities that directly support the programme

Please do **not** submit competition entries as pull requests here.

## Workflow

1. Fork the repository.
2. Create a focused branch.
3. Make your change.
4. Test it where applicable.
5. Open a pull request explaining what changed and why.

Keep pull requests small and easy to review.

## Code

For Python examples:

- prefer the standard library where practical
- keep dependencies minimal
- write clear functions and comments
- include a small test when behaviour changes
- avoid committing secrets, generated artefacts or large datasets

## Documentation

Write for someone encountering the material for the first time.

Prefer:

- direct language
- short examples
- explicit assumptions
- clear limitations

If you make a measurement or sustainability claim, state what was actually measured and avoid implying more than the evidence supports.

## Conduct

All contributors must follow the [Code of Conduct](CODE_OF_CONDUCT.md).
