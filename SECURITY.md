# Security Policy

Thank you for helping keep this repository and its examples safe.

## Scope

This repository contains reference code, documentation and technical examples for Hack for Earth 2026. It is not a production service and no long-term support commitment is implied.

## Reporting a vulnerability

Please **do not open a public issue containing exploit details, secrets or sensitive vulnerability information**.

Where GitHub private vulnerability reporting is available for this repository, use that channel. Otherwise, contact the organisers through an official Green Reliable Software Budapest or Hack for Earth community channel and request a private reporting route.

For non-sensitive security improvements, a normal issue or pull request is welcome.

## Expectations

Please give maintainers reasonable time to understand and address a report before public disclosure.
