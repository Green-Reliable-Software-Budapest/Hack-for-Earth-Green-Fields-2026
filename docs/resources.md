# Resources

HACK4EARTH 2.0 does not require a common dataset or technology stack.

Participants may use public datasets, APIs, open-source models, their own legitimately collected data, simulations or no dataset at all.

## Useful starting points

### Green software

- Green Software Foundation: https://greensoftware.foundation/
- Software Carbon Intensity specification: https://sci.greensoftware.foundation/

### Open source

- Open Source Initiative: https://opensource.org/
- GitHub Open Source Guides: https://opensource.guide/

### Public environmental and geospatial data

- Copernicus: https://www.copernicus.eu/
- European Environment Agency: https://www.eea.europa.eu/
- Open-Meteo: https://open-meteo.com/
- Our World in Data: https://ourworldindata.org/

### Security

- OWASP: https://owasp.org/
- OpenSSF: https://openssf.org/

## Resource policy

External data, models, tools and APIs should be used in accordance with their licences and terms.

If a paid or restricted dependency is essential to a project, disclose that limitation in the final Writeup.

This page is a starting point, not a prescribed stack.
