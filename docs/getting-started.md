# Getting Started

HACK4EARTH 2.0 is an open-ended Green + Open Software hackathon.

The competition is hosted on Kaggle:

**https://www.kaggle.com/competitions/hack-4-earth-2-0-greener-fields**

## 1. Choose a problem

Start with a real technical problem connected to one or more of:

- **SECURE**
- **EFFICIENT**
- **RESILIENT**

Select one primary track for judging.

## 2. Define a claim you can test

Before adding technology, write down what you expect your project to improve.

Examples:

- reduce a measurable software resource cost
- identify a security weakness
- improve recovery under a defined failure condition
- make an environmental observation easier to validate
- reduce latency, memory use or compute demand for a task

A strong project does not need a large scope. It needs a clear problem and credible evidence.

## 3. Build openly

Use a public source-code repository for the submitted work.

Include:

- a README
- setup instructions
- dependencies
- an OSI-approved open-source licence
- enough information for another person to inspect or run the project

## 4. Test what you claim

Evidence may include:

- tests
- benchmarks
- security analysis
- simulations
- experiments
- energy or carbon measurements
- field observations
- validation data

Use evidence appropriate to the claim.

## 5. Submit on Kaggle

Do not submit your competition project as a pull request to this repository.

Use the official Kaggle Writeup flow for your final entry.
