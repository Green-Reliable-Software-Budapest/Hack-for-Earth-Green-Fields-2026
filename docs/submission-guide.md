# Submission Guide

Each team submits one final project through Kaggle.

Your Writeup should make it possible for judges to understand:

1. the problem
2. what you built
3. how it works
4. what you measured or validated
5. what was completed during Hack for Earth
6. how someone else can inspect or reproduce the work

## Required elements

### Project title

Use a clear project name.

### Primary track

Choose one:

- SECURE
- EFFICIENT
- RESILIENT

### Problem

Explain what problem you are addressing, who or what is affected, and why it matters.

### Solution

Describe the actual system, tool, prototype or technical intervention.

### Technical implementation

Explain the architecture, stack, APIs, infrastructure, models, hardware or important technical decisions where relevant.

### Evidence

Provide evidence appropriate to your claims.

This may include tests, benchmarks, measurements, security analysis, simulations, experimental results, field observations or validation data.

### Source code

Provide a public repository with setup instructions and an open-source licence.

### Demo

Where useful, provide screenshots, a live demo, notebook or short video.

### Work completed during the programme

If the project existed before October 2026, distinguish clearly between pre-existing work and what was added or substantially improved during the hackathon.

## Deadline

Refer to the official Kaggle Timeline for the definitive submission deadline.
